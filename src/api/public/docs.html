Only-NONE Bot API

RESTful API for Discord bot integrations

API v1.0.0

Authentication

All API endpoints require authentication using an API key. You can generate API keys using the /api create command in Discord.

How to Use API Keys:

# Using Header (Recommended)
curl -H "X-API-Key: your-api-key-here" \ https://your-bot-url.com/api/v1/info
# Using Query Parameter
curl "https://your-bot-url.com/api/v1/info?api_key=your-api-key-here"

Key Permissions:

  • read - Read access to basic information
  • write - Modify data (where applicable)
  • economy - Access economy endpoints
  • moderation - Access moderation endpoints
  • admin - Full administrative access

Base URL

https://your-bot-url.com/api/v1

API Endpoints

GET /health

Check API health status

Response:
{ "status": "healthy", "version": "v1", "timestamp": "2023-12-01T12:00:00.000Z", "uptime": 3600 }

GET /info

Get API and key information

Response:
{ "api": { "version": "v1", "name": "Only-NONE Bot API", "description": "REST API for Only-NONE Discord bot", "documentation": "https://your-bot-url.com/api/v1/docs" }, "key": { "id": "key_id", "name": "My API Key", "permissions": ["read", "economy"], "rateLimit": 60, "usage": { "requests": 150, "lastUsed": "2023-12-01T11:30:00.000Z" } } }

GET /users/{userId}

Parameters:

GET /guilds/{guildId}/members

Get guild members with pagination and filtering

Parameters:
  • guildId (string, path) - Discord guild ID
  • page (integer, query) - Page number (default: 1)
  • limit (integer, query) - Results per page (max: 1000)
  • search (string, query) - Search by username or nickname
  • filter (string, query) - Filter by bots/humans/online
Response:
{ "members": [...], "pagination": { "page": 1, "limit": 100, "total": 1000, "pages": 10, "hasNext": true, "hasPrev": false } }

GET /guilds/{guildId}/economy/users

Get economy users with pagination

Permissions Required:
economy
Parameters:
  • guildId (string, path) - Discord guild ID
  • page (integer, query) - Page number (default: 1)
  • limit (integer, query) - Results per page (max: 100)
  • sort (string, query) - Sort field (balance/totalBalance)
  • order (string, query) - Sort order (asc/desc)

GET /guilds/{guildId}/economy/user/{userId}

Get specific user economy data

Permissions Required:
economy
Parameters:
  • guildId (string, path) - Discord guild ID
  • userId (string, path) - Discord user ID

POST /guilds/{guildId}/economy/user/{userId}/balance

Update user balance

Permissions Required:
economy
Parameters:
  • guildId (string, path) - Discord guild ID
  • userId (string, path) - Discord user ID
Request Body:
{ "amount": 1000, "type": "add", "reason": "Bonus payment" }
Body Fields:
  • amount (number) - Amount to add/remove
  • type (string) - "add" or "remove"
  • reason (string) - Reason for the change

GET /guilds/{guildId}/moderation/cases

Get moderation cases

Permissions Required:
moderation
Parameters:
  • guildId (string, path) - Discord guild ID
  • page (integer, query) - Page number (default: 1)
  • limit (integer, query) - Results per page (max: 100)
  • type (string, query) - Filter by case type
  • status (string, query) - Filter by case status

POST /guilds/{guildId}/moderation/cases

Create a new moderation case

Permissions Required:
moderation
Request Body:
{ "caseType": "WARN", "userID": "123456789", "userTag": "username#1234", "moderatorID": "987654321", "moderatorTag": "moderator#5678", "reason": "Spamming in general chat", "severity": 2, "evidence": ["Screenshot of spam messages"] }
Required Fields:
  • caseType (string) - Case type (WARN, KICK, BAN, etc.)
  • userID (string) - Target user ID
  • userTag (string) - Target user tag
  • moderatorID (string) - Moderator user ID
  • moderatorTag (string) - Moderator user tag
  • reason (string) - Case reason
Optional Fields:
  • severity (number) - Severity level (1-5)
  • duration (number) - Duration for temporary actions
  • evidence (array) - Evidence array

Error Handling

The API returns standard HTTP status codes and JSON error responses:

{ "error": "Error type", "message": "Detailed error message", "details": "Additional error details (if available)" }

Common Status Codes:

  • 200 - Success
  • 201 - Created
  • 400 - Bad Request
  • 401 - Unauthorized
  • 403 - Forbidden
  • 404 - Not Found
  • 429 - Rate Limited
  • 500 - Internal Server Error

Rate Limiting

API keys have configurable rate limits:

  • Per-minute limit (default: 60 requests)
  • Per-day limit (default: 10,000 requests)
  • Rate limit headers included in responses
X-RateLimit-Limit: 60 X-RateLimit-Remaining: 59 X-RateLimit-Reset: 1638360000

Code Examples

JavaScript (Node.js)

const axios = require('axios'); const api = axios.create({ baseURL: 'https://your-bot-url.com/api/v1', headers: { 'X-API-Key': 'your-api-key-here' } }); // Get guild information async function getGuildInfo(guildId) { try { const response = await api.get(`/guilds/${guildId}`); console.log(response.data); } catch (error) { console.error('Error:', error.response.data); } } // Update user balance async function updateBalance(guildId, userId, amount, type, reason) { try { const response = await api.post(`/guilds/${guildId}/economy/user/${userId}/balance`, { amount, type, reason }); console.log('Balance updated:', response.data); } catch (error) { console.error('Error:', error.response.data); } }

Python

import requests class BotAPI: def __init__(self, base_url, api_key): self.base_url = base_url self.headers = {'X-API-Key': api_key} def get_guild_info(self, guild_id): response = requests.get( f'{self.base_url}/guilds/{guild_id}', headers=self.headers ) return response.json() def update_balance(self, guild_id, user_id, amount, type_, reason=None): data = { 'amount': amount, 'type': type_ } if reason: data['reason'] = reason response = requests.post( f'{self.base_url}/guilds/{guild_id}/economy/user/{user_id}/balance', json=data, headers=self.headers ) return response.json() # Usage api = BotAPI('https://your-bot-url.com/api/v1', 'your-api-key') guild_info = api.get_guild_info('123456789') print(guild_info)
